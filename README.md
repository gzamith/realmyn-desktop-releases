# Realmyn Desktop

Este repositório distribui somente instaladores e arquivos de atualização do **Realmyn para Windows x64**.

Baixe a versão mais recente na seção **Releases**. O aplicativo conecta ao mesmo sistema online do Realmyn e exige internet.

## Versão piloto

O instalador 0.1.0 ainda não possui assinatura digital. O Windows pode informar publicador desconhecido. Use somente arquivos desta página oficial.

## Atualizações

Mudanças do sistema online aparecem ao reabrir ou recarregar o aplicativo. Novas versões do aplicativo são baixadas em segundo plano; a instalação aguarda sua escolha de reiniciar. Não há reinicialização forçada durante chamadas.

O código-fonte do sistema não é publicado neste repositório.
